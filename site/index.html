Study design

Each condition uses the same seeded dataset samples, with a target of 64 items per source. A traced forward captures four token positions at every layer visit. Agent traces replay recorded text and tool responses. ARC-Challenge and HellaSwag are scored as four-letter forced-choice tasks.

NDIF runs both checkpoints at three passes. The local sweep uses the IQ4_NL quantization of each checkpoint. The active block is the running sum within the current six-layer block.
